    Try your own starting values

    Enter 1–24 whole numbers from 0 to 99, separated by spaces or commas. Applying custom values replaces the current input for all three traces. Changing the pattern or size returns to generated values.

    Try an already sorted input: bubble sort can stop after a swap-free pass, while a rightmost pivot can leave quicksort with uneven partitions. Input shape matters; fewer swaps alone do not establish a faster implementation.
